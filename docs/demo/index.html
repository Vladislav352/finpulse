Как считаем

Выручка = realisation TrueStats, реализация до СПП, сумма по кабинетам.

Маржинальность = profit / realisation. Прибыль TrueStats: после комиссии, логистики, хранения, рекламы, налога и себестоимости.

Рентабельность себестоимости = profit / costOfSales. Себестоимость в карточках TrueStats сверена финдиректором 14.09; себестоимость проданного может отличаться от текущей, пока продаются остатки, заведённые до изменения цены закупки.

ДРР = advertisingExpenseSum / realisation, все типы кампаний.

Оплата на р/с по факту = totalPaid TrueStats: сумма, которую площадки перечисляют на расчётный счёт за продажи периода. Равна прибыль + себестоимость + налог; формула «прибыль + себестоимость» даёт ту же величину без налога, потому что налог площадка не удерживает. Считается по отчётам реализации, поэтому за текущий месяц сумма растёт по мере закрытия недель.

Семейства: по префиксу артикула, наборы сведены к базовому SKU.

Статусы: красное — убыток или меньше 60% плана, жёлтое — ниже цели, зелёное — в цели.
